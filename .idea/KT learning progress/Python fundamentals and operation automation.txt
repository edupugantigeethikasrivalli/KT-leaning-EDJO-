1. Introduction to Operations Automation
Operations automation is the process of using scripts to perform repetitive operational tasks automatically, reducing manual effort and human errors.
Applications:
- Log analysis — count errors and warnings in log files.
- System monitoring — check CPU, memory, and disk usage.
- File management — read, write, and organize files.
- API automation — send requests and process API responses.
- Task automation — generate reports and automate routine checks.
2. Variables in Python
A variable is a named reference used to store a value that can be used later in a program.
Syntax:
variable_name = value



Example:
server_name = "server-01"cpu_usage = 75memory_usage = 68.5is_server_running = Trueprint(server_name)print(cpu_usage)print(memory_usage)print(is_server_running)



Output:
server-01
75
68.5
True


Variable naming rules:
- Names can contain letters, digits, and underscores.
- A name cannot start with a digit.
- Names are case-sensitive.
- Python keywords cannot be used as variable names.
- Use descriptive names such as cpu_usage and error_count.
3. Python Data Types
Data types define the kind of value stored in a variable.
Data type	Description	Example
str	Text	"RUNNING"
int	Whole numbers	100
float	Decimal numbers	82.5
bool	Boolean values	True, False
Example:
server_status = "RUNNING"error_count = 10cpu_usage = 82.5service_up = Trueprint(type(server_status))print(type(error_count))print(type(cpu_usage))print(type(service_up))



The type() function returns the data type of a value.
Importance in operations automation:
- str stores server names, statuses, and log messages.
- int stores error counts and process IDs.
- float stores measurements such as CPU utilization.
- bool represents conditions such as whether a service is running.
4. Operators in Python
Operators perform calculations and comparisons.
A. Arithmetic operators
Operator	Purpose	Example	Result
+	Addition	10 + 5	15
-	Subtraction	10 - 5	5
*	Multiplication	10 * 5	50
/	Division	10 / 5	2.0
%	Remainder	10 % 3	1
//	Floor division	10 // 3	3
**	Exponentiation	2 ** 3	8
Example:

B. Comparison operators
Comparison operators compare values and return True or False.
Operator	Meaning	Example
>	Greater than	90 > 80 → True
<	Less than	60 < 80 → True
>=	Greater than or equal to	80 >= 80 → True
<=	Less than or equal to	70 <= 80 → True
==	Equal to	200 == 200 → True
!=	Not equal to	200 != 500 → True
Important: = assigns a value; == checks whether two values are equal.
5. Conditional Statements
Conditional statements allow a program to make decisions based on conditions.
Example:
cpu_usage = 85.5threshold = 80if cpu_usage > threshold:    print("WARNING: High CPU usage detected!")else:    print("CPU usage is normal.")



Output:
WARNING: High CPU usage detected!


Explanation:
1. Store the CPU usage in cpu_usage.
2. Set the threshold to 80.
3. Compare CPU usage with the threshold.
4. Print a warning if the usage exceeds the threshold; otherwise, print a normal-status message.

7. File Handling in Python
File handling allows Python to read, write, and process files. It is useful for analyzing application logs, configuration files, and operational reports.
Common file modes
Mode	Purpose
"r"	Read a file
"w"	Write to a file, replacing existing content
"a"	Append content to a file
"rb"	Read a file in binary mode
Example: Reading a file
Create a file named operations.log containing:
INFO: Application started
ERROR: Database connection failed
INFO: Request completed
ERROR: API request failed


Python code:
with open("operations.log", "r") as file:    content = file.read()print(content)



Explanation:
- open() opens the file.
- "r" specifies read mode.
- read() reads the file content.
- with automatically closes the file after the block finishes.
Count errors in a log file
error_count = 0with open("operations.log", "r") as file:    for line in file:        if "ERROR" in line:            error_count += 1print("Total errors:", error_count)



Output:
Total errors: 2


Operations use case: Automatically identify how many errors occurred in an application log.
8. Parsing Data in Python
Data parsing means reading raw data and extracting useful information from it.
Operational scripts commonly parse logs, CSV files, JSON responses, and configuration files.
Example: Parsing log lines
log_line = "ERROR: Database connection failed"parts = log_line.split(":", 1)level = parts[0]message = parts[1].strip()print("Level:", level)print("Message:", message)



Output:
Level: ERROR
Message: Database connection failed


Here:
- split(":", 1) separates the log level from the message at the first colon.
- strip() removes extra whitespace from the message.
Parsing JSON data

9. Calling a Sample API
An API (Application Programming Interface) allows one application to communicate with another application.
For example, an operations script can call an API to retrieve service information, incident details, or monitoring data.
Install the requests library
Run this command in your terminal:
python -m pip install requests


Example: Call a sample API
We'll use JSONPlaceholder, a public sample API.
import requestsurl = "https://jsonplaceholder.typicode.com/posts/1"response = requests.get(url, timeout=10)print("Status code:", response.status_code)data = response.json()print("Title:", data["title"])



The API returns sample post data in JSON format.
Important concepts:
Concept	Meaning
requests.get()	Sends an HTTP GET request
timeout=10	Limits how long the request waits
status_code	Shows the HTTP response status
response.json()	Parses the JSON response into Python data
A status code of 200 usually means the HTTP request succeeded. Always check the response before relying on its data.
10. Error Handling in Python
Error handling prevents a script from crashing unexpectedly when a problem occurs.
Python uses try, except, else, and finally to handle exceptions.
Keyword	Purpose
try	Contains code that may fail
except	Handles an exception
else	Runs if the try block succeeds
finally	Runs whether an exception occurs or not
Example: Handling a missing file
try:    with open("operations.log", "r") as file:        print(file.read())except FileNotFoundError:    print("Error: Log file not found.")except OSError as error:    print("File operation failed:", error)



This script handles a missing file or another operating-system file error instead of leaving the failure unhandled.
Example: Handling API errors
import requeststry:    response = requests.get(        "https://jsonplaceholder.typicode.com/posts/1",        timeout=10    )    response.raise_for_status()    data = response.json()    print("API call successful")    print(data["title"])except requests.exceptions.Timeout:    print("Error: API request timed out.")except requests.exceptions.HTTPError as error:    print("HTTP error:", error)except requests.exceptions.RequestException as error:    print("Network or request error:", error)except ValueError:    print("Error: Invalid JSON response.")



raise_for_status() raises an HTTP error for unsuccessful HTTP status codes such as 404 or 500. The exception handlers then process the relevant failures.
